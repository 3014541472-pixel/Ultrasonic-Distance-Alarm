# 51 单片机超声波测距报警

使用超声波模块测量障碍物距离。LCD1602 第一行显示距离（cm），第二行显示报警等级。程序根据距离调整低电平触发的有源蜂鸣器在每个 PWM 周期内开启的比例。

| 距离 | LCD 等级 | 蜂鸣器开启比例 |
| --- | --- | --- |
| ≤ 10 cm | H | 100% |
| > 10 cm 且 ≤ 20 cm | M | 50% |
| > 20 cm 且 ≤ 30 cm | L | 25% |
| > 30 cm | N | 0% |

## 引脚

| 模块信号 | 51 单片机端口 |
| --- | --- |
| TRIG（Trigger Input，测量触发输入） | P1.6 |
| ECHO（Echo Output，回波脉冲输出） | P1.5 |
| Buzzer（蜂鸣器控制，低电平有效） | P3.7 |
| LCD RS（Register Select，寄存器选择） | P2.6 |
| LCD R/W（Read/Write，读写选择） | P2.5 |
| LCD EN（Enable，使能） | P2.7 |
| LCD D0–D7（Data Bits，8 位数据线） | P0.0–P0.7 |

## 工程说明

用安装了 C51 工具链的 Keil µVision 打开 `Project.uvproj`，选择 **Rebuild**。工程目标为 AT89C52。

- `main.c` 负责报警分级、屏幕刷新和 Timer 1 中断中的蜂鸣器 PWM。
- `UT.c` 发送触发脉冲，并用 Timer 0 计时，根据 ECHO 高电平持续时间估算距离。
- `LCD1602.c` 负责显示驱动，`Delay.c` 提供延时函数。
- `PWM.c` 是工程引用的空文件，随原工程保留。
